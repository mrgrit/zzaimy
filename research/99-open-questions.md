# 사용자 확인 필요 사항 (누적)

> Phase 0 진행 중 발견된, 사용자만 답할 수 있는 질문들. Phase 0 보고 시 일괄 제시.

## A. 문서 파싱 관련

1. **HWP/HWPX 문서 비율** — 보유 문서와 신규 공고문 중 HWP/HWPX 원본이 있는가? 한국 공공기관 특성상 공고문이 HWP로 배포되는 경우가 많다. HWP가 섞여 있다면 PDF 파싱과 별도의 처리 경로(HWPX 직접 파싱)가 필요하다.
2. **스캔본 비율과 품질** — 수만 장 중 스캔 PDF(이미지)와 born-digital PDF(텍스트 레이어 존재)의 대략적 비율은? 스캔본의 해상도·기울어짐·도장/필기 오염 수준은?
3. **표의 형태** — 결과보고서의 실적 표가 주로 ①워드/한글에서 생성된 선명한 표인가 ②스캔된 표인가 ③엑셀 첨부인가?
4. **문서 실물 표본 제공 가능 시점** — bake-off용으로 결과보고서 표본(민감정보 마스킹 전이라도 개발장비 내 처리 전제) 30~50페이지를 언제 받을 수 있는가?
